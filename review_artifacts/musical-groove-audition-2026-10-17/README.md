# Musical Groove Audition Set

Each stereo WAV is an eight-bar, 96 BPM comparison render for rock, folk, or indie. The backing is synthesized guitar- and voice-like material, not a recording of a performer. Use it to compare the candidate timing/articulation treatments, then validate the preferred choices against real playing before setting product defaults.

For each style:

- `straight`: straight eighth-note grid, no added ghost snares.
- `swing-55`: 55% eighth-note swing, approximately 31 ms offbeat delay.
- `swing-60`: 60% eighth-note swing, approximately 63 ms offbeat delay.
- `swing-55-ghost-014`: 55% swing plus offbeat ghost snares at velocity 0.14.

The first twelve renders use the same accompaniment intensity and backing to isolate timing/articulation. The six intensity renders compare 0.2 and 0.9 using the selected relaxed treatment. Drum samples come from the bundled starter kit. The initial timing candidates have been used to select the current implementation; the intensity renders remain for musician review.

The selected app treatment is 55% swing, with offbeat ghost snares for rock and folk but not indie. The page also includes relaxed-feel low/high intensity pairs at 0.2 and 0.9 for all three styles. Use these pairs to judge whether the intensity range keeps the groove recognizable and balanced.

## Musician Feedback

- Rock: selected Swing 55 with ghost snares.
- Folk: selected Swing 55 with ghost snares.
- Indie: selected Swing 55 without added ghost snares.
- Intensity 0.2 versus 0.9: not judged; synthesized backing is insufficient. Validate with a real guitar-and-voice recording before tuning intensity defaults.
